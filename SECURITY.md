# Security Policy

This repository is a public, sanitized showcase for Albus.

## Intentionally excluded

- Marketplace API tokens
- OpenAI or other AI provider keys
- Database credentials
- Customer or seller data
- Private production endpoints
- Commercial production source code

## Reporting

If you discover a security issue related to the public showcase, please avoid publishing sensitive details in a public issue. Contact the project owner directly through the official project channels.
