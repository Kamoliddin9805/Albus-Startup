# Security & Public Disclosure Policy

This repository is a **sanitized public startup showcase** for Albus. It is not the production repository.

## Public boundary

The materials here are limited to evaluation-safe product descriptions, high-level architecture and non-production reference code.

## Never included

- marketplace API tokens or credentials;
- OpenAI / AI-provider keys;
- database credentials or connection strings;
- customer, seller or order data;
- private production endpoints;
- production source code;
- infrastructure configuration;
- AI system prompts or private retrieval instructions;
- provider-specific marketplace mappings;
- proprietary enrichment, ranking or automation rules;
- internal operational thresholds.

## Secret handling principle

Production credentials are expected to remain server-side and outside browser-delivered code and public repositories.

## Reporting

If a security issue is found in this public showcase, please do not disclose sensitive details in a public GitHub issue. Contact the project owner through the official Albus channels.

## Evaluation notice

Nothing in this file or repository should be interpreted as disclosure of the complete Albus production security model. Security-sensitive implementation details remain private by design.
